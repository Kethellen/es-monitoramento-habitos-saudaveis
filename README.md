# 🌱 Projeto ODS - Monitoramento de Hábitos Saudáveis

## 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver uma solução de software alinhada a um dos Objetivos de Desenvolvimento Sustentável (ODS), propostos pela ONU.

A aplicação consiste em um sistema web para auxiliar usuários no monitoramento de hábitos saudáveis, promovendo melhoria na qualidade de vida.

---

## 🎯 ODS Escolhido

**ODS 3 – Saúde e Bem-Estar**

> Garantir o acesso à saúde de qualidade e promover o bem-estar para todos, em todas as idades.

---

## ❗ Problema

Muitas pessoas enfrentam dificuldades para manter hábitos saudáveis no dia a dia, como:

* Beber água regularmente
* Praticar atividades físicas
* Manter uma rotina de sono adequada

Além disso, não há ferramentas simples e acessíveis para acompanhamento desses hábitos, o que impacta diretamente a saúde e qualidade de vida.

---

## 💡 Solução Proposta

Será desenvolvido um sistema web que permitirá ao usuário:

* Registrar hábitos diários
* Acompanhar seu progresso
* Visualizar dados por meio de gráficos
* Gerenciar seus registros

A aplicação contará com:

* Frontend web (interface do usuário)
* Backend em Java (API REST)
* Banco de dados para persistência
