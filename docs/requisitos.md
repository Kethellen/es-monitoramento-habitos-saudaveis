## Problema

Muitas pessoas não conseguem manter hábitos saudáveis no dia a dia, como beber água regularmente, praticar exercícios ou manter uma rotina de sono adequada. Além disso, há dificuldade em acompanhar esses hábitos de forma simples e acessível.

Isso impacta diretamente a saúde e qualidade de vida, contribuindo para problemas como sedentarismo, desidratação e estresse.

## Solução Proposta

Será desenvolvido um sistema web para monitoramento de hábitos saudáveis, onde o usuário poderá:

- Registrar hábitos diários (água, exercícios, sono)
- Acompanhar seu progresso por meio de gráficos
- Receber lembretes e feedbacks

A aplicação terá:
- Frontend (interface web)
- Backend em Java (API)
- Banco de dados para armazenamento dos dados

A escolha dessa abordagem permite praticar conceitos completos de engenharia de software, incluindo frontend, backend e persistência de dados.

## Requisitos Funcionais

RF01 - O sistema deve permitir o cadastro de usuários  
RF02 - O sistema deve permitir login de usuários  
RF03 - O usuário deve poder registrar consumo de água  
RF04 - O usuário deve poder registrar atividades físicas  
RF05 - O usuário deve visualizar histórico de hábitos  
RF06 - O sistema deve exibir gráficos de progresso  
RF07 - O sistema deve permitir edição de registros  
RF08 - O sistema deve permitir exclusão de registros  

## Requisitos Não Funcionais

RNF01 - O sistema deve ser acessível via navegador web  
RNF02 - O tempo de resposta deve ser inferior a 2 segundos  
RNF03 - O sistema deve garantir segurança dos dados do usuário  
RNF04 - A interface deve ser intuitiva e responsiva  
RNF05 - O sistema deve estar disponível 24/7
